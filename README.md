# X Money pay page

Single-file landing page that points senders at **@badbottombitch1** on X Money.

X Money has no public checkout URL. This page copies the handle, states the amount / menu item, and opens the X profile. The actual send happens in the X app:

1. Money tab → Send
2. Paste `@badbottombitch1`
3. Amount + note
4. DM the request

## Live it

Repo is public. Turn on GitHub Pages:

1. GitHub → this repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save

URL will be:

`https://dadamscoder647.github.io/xpay/`

Put that URL in the X profile website field and pin a post with it.

## Edit the menu

Open `index.html` and change the offer cards or the `HANDLE` constant in the script at the bottom.
